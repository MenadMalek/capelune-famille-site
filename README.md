# Capelune Famille — Planning visuel facile

Version web installable de Capelune Famille, destinée aux familles.

- Planning visuel à la journée, demi-journée ou semaine.
- Séquençage de routines avec fiches personnalisées.
- Export PDF et enregistrement local dans le navigateur.
- Installation sur l’écran d’accueil avec l’icône Capelune.

Site : https://famille.capelune.fr/
